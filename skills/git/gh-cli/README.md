# 🐙 GitHub CLI (`gh-cli`)

> **Automates GitHub workflows with the `gh` CLI and scripts: Pull Requests with Conventional Commits, emojis and verified labels, GitHub Actions diagnostics, issues, and releases with generated notes.**

| Property | Value |
| :--- | :--- |
| **Name** | `gh-cli` |
| **Category** | `git` |
| **Version** | `1.1.0` |
| **Compatible Agents** | Antigravity, Claude Code, OpenAI Codex, Cursor, Windsurf |
| **Requirements** | `gh`, `git`, `bash` |

---

## 📦 Installation

### With the `skills.sh` CLI (recommended)

```bash
# Install into the current project:
npx skills add bryanus1/agent-skills --skill gh-cli

# Install globally on your machine:
npx skills add bryanus1/agent-skills --skill gh-cli -g
```

### With a local symlink

```bash
# Google Antigravity:
mkdir -p .agents/skills
ln -s /path/to/agent-skills/skills/git/gh-cli .agents/skills/gh-cli

# Claude Code:
mkdir -p .claude/skills
ln -s ../../.agents/skills/gh-cli .claude/skills/gh-cli
```

## 💡 Usage Examples with AI Agents

The skill replies in the user's language, so you can ask in English or Spanish.

* **Create a standardized Pull Request**:
  > *"Open a PR from my feat/42-login-form branch for the auth domain and request a review from octocat"*
  >
  > 🤖 **The agent runs**: `bash <skill-dir>/scripts/create_pr.sh --domain auth --reviewer octocat --dry-run` and, after you confirm, the same command without `--dry-run`  
  > ➔ Title `feat(#42): ✨ login form`, labels `enhancement` and `domain: auth` (checked in the repo before anything is created) and a body with `Closes #42`.

* **Diagnose a failed GitHub Actions check**:
  > *"The lint check on my PR #57 is red"*
  >
  > 🤖 **The agent runs**: `bash <skill-dir>/scripts/diagnose_run.sh --pr 57 --job lint`  
  > ➔ Shows the PR checks and only the failed lines of the `lint` job in the latest failed run.

* **Publish a release**:
  > *"Publish release v1.4.0"*
  >
  > 🤖 **The agent runs**: `bash <skill-dir>/scripts/release_helper.sh create v1.4.0 --dry-run` and, after you confirm, creates it with notes generated by GitHub.

## 🛠️ Scripts and CLI Options

> `<skill-dir>` is the directory where this skill is installed (e.g. `.agents/skills/gh-cli` or `.claude/skills/gh-cli`).

- **[`scripts/check_env.sh`](scripts/check_env.sh)**: Checks `git`, `gh`, the active session and the remote repository.
- **[`scripts/create_pr.sh`](scripts/create_pr.sh)**: Creates PRs with Conventional Commits, emojis, up-front label checks and `--dry-run` support.
- **[`scripts/diagnose_run.sh`](scripts/diagnose_run.sh)**: Inspects the latest failed run of the branch or PR (`--pr <n> --job <name> --lines <n>`).
- **[`scripts/release_helper.sh`](scripts/release_helper.sh)**: `list`, `view`, `draft-notes` and `create <tag> [--dry-run]` commands.
