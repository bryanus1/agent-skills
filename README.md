## 📖 Overview

**Agent Skills Hub** is an open, standardized ecosystem of modular skills that teach AI agents and assistants how to carry out complex tasks with high precision and consistency.

It is built on the principle of **Progressive Disclosure**:
1. **Discovery (Level 1)**: only `name` and `description` are loaded into the initial prompt.
2. **Activation (Level 2)**: the agent reads `SKILL.md` only when the task matches the `triggers`.
3. **Deep dive (Level 3)**: documentation in `references/` or utilities in `scripts/` are read only when needed.

Skills are written in English and have bilingual (Spanish and English) `triggers`, and each one tells the agent to reply in the user's language.

### 🧭 IDD Flow (Issue-Driven Development)

Three lightweight, Markdown-only skills inspired by Spec-Driven Development: **`idd-explore`** (refines the requirement) → **`idd-plan`** (a detailed plan with requirements, scenarios, tasks and verification) → **`idd-apply`** (implements it and ticks the tasks). Each change lives in a single place: the item in your tracker (Notion, Linear, GitHub Issues/Projects) or, if you use none, `docs/specs/<YYYY-MM-DD>-<slug>.md`.

```bash
npx skills add bryanus1/agent-skills --skill idd-explore --skill idd-plan --skill idd-apply
```

## 📦 How to Install and Use the Skills

You can install these skills straight from GitHub into any project or AI assistant using the [`skills.sh`](https://skills.sh) CLI or local symlinks. See each skill's `README.md` (linked in the table above) for its dependencies and activation examples.

### 1. Via the official CLI (`skills.sh`) — *Recommended*

```bash
# List all the skills available in this repository:
npx skills add bryanus1/agent-skills --list

# Install a specific skill in your current project:
npx skills add bryanus1/agent-skills --skill <skill-name>

# Install a skill globally on your machine (available to all your projects):
npx skills add bryanus1/agent-skills --skill <skill-name> -g

# Install every skill in the repository:
npx skills add bryanus1/agent-skills --all
```

### 2. Via a Local Symlink

If you have this repository cloned on your machine and want changes to be reflected automatically:

```bash
# For Google Antigravity:
mkdir -p .agents/skills
ln -s /path/to/agent-skills/skills/<category>/<skill-name> .agents/skills/<skill-name>

# For Claude Code:
mkdir -p .claude/skills
ln -s ../../.agents/skills/<skill-name> .claude/skills/<skill-name>
```

## 🤝 How to Contribute and Work in this Repo

To keep quality high and the standard agent-agnostic, read the [**Contribution Guide (`docs/CONTRIBUTING.md`)**](docs/CONTRIBUTING.md) and the [**Technical Specification (`docs/SPECIFICATION.md`)**](docs/SPECIFICATION.md).

### Development workflow summary:

1. **Create a branch**: `git checkout -b feat/my-new-skill`.
2. **Pick a template**: copy from `templates/basic-skill` or `templates/tool-assisted-skill`.
3. **Write `SKILL.md` and `README.md`**: define valid YAML frontmatter in `SKILL.md` (`name`, `version`, `description` < 350 chars, `triggers`) and document installation and usage examples in `README.md`.
4. **Validate with the linter, regenerate the catalog and run the tests**:
   ```bash
   pnpm lint:strict
   pnpm catalog
   pnpm test
   ```
5. **Commit with Conventional Commits**: `feat(category): add my-new-skill`.
